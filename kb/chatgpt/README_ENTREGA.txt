BASE DE CONOCIMIENTO DE C — ENTREGA PARCIAL

Archivos:
- errores.json: 50 registros únicos de Sintaxis y escritura, numerados 1–50.
- ayuda.json: 153 entradas contextuales.
- lecciones.json: 35 mini-lecciones con ejemplos compilables.
- auditoria_consolidacion.md: tabla, TOP 50, dudas, casos dinámicos y UB, y pendientes.

Validación: GCC 14.2, -std=gnu99 -Wall -Wextra. Los diagnósticos exactos pueden cambiar respecto de GCC 13. Los archivos JSON fueron parseados en Python 3.13.
