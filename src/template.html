    Cómo se escribió el programa
    
    El editor mide, solo en este dispositivo, cuántos caracteres tipeaste, cuántos pegaste o abriste desde un archivo, cuánto tiempo trabajaste y cuántas veces ejecutaste. No guarda lo que escribís aparte del programa y no se envía a ningún lado. Si querés, aparece como una línea al pie de la captura que entregás. Es un dato del proceso, no una prueba.
    
    
    
    
  
    
  
    Casos para enviar
    
    Cuando el editor no sabe explicar algo, guarda el caso solo en este dispositivo. Nada se envía solo: vos mirás qué se manda y elegís si se lo mandás a Diego.

      Atajos y alcance
      
  
      Interpreta el C que se usa en la materia. No es gcc: si algo se comporta distinto, avisá.
      
  
        
    
      • Tipos: int, float, double, char, long, unsigned.
        • 
    
      • Control: if / else, switch, while, do-while, for, break, continue.
        • 
    
      • Funciones con parámetros, retorno y recursión; arreglos de 1 y 2 dimensiones.
        • 
    
      • Entrada y salida: printf, scanf, getchar, putchar, puts (con todos los formatos: %d %f %.2f %c %e %g %x …).
        • 
    
      • Biblioteca: math.h (sqrt, pow, abs…), rand, ctype.h básico, #define de constantes.
        • 
    
      • Avisos útiles: te marca %d con float, scanf sin &, variables sin valor inicial, = dentro de if…
        • 
    
      • Todavía no: punteros en general, struct, enum, typedef, archivos.
        •
