Qué soporta este editor

    
Interpreta el C que se usa en la materia. No es gcc: si algo se comporta distinto, avisá.

    
    
      
  • Tipos: int, float, double, char, long, unsigned.
    • 
      
  • Control: if / else, switch, while, do-while, for, break, continue.
    • 
      
  • Funciones con parámetros, retorno y recursión; arreglos de 1 y 2 dimensiones.
    • 
      
  • Entrada y salida: printf, scanf, getchar, putchar, puts (con todos los formatos: %d %f %.2f %c %e %g %x …).
    • 
      
  • Biblioteca: math.h (sqrt, pow, abs…), rand, ctype.h básico, #define de constantes.
    • 
      
  • Avisos útiles: te marca %d con float, scanf sin &, variables sin valor inicial, = dentro de if…
    • 
      
  • Todavía no: punteros, textos (char[] con %s), struct, archivos.
    • 
    

    
Tu código no sale de tu navegador. Se guarda solo en este dispositivo.
